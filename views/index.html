About This Project

This is a Wildlife Sighting Tracker web app. It is built with Express.js. You can use the API to get data about wildlife sightings.

API Endpoints

Click on any endpoint to try it:

GET /api/sightings

Get all wildlife sightings

GET /api/sightings/verified

Get only verified sightings

GET /api/sightings/species-list

Get list of species names

GET /api/sightings/habitat/forest

Get forest habitat sightings

GET /api/sightings/search/eagle

Search for eagle sightings

GET /api/sightings/find-index/moose

Find moose index in database

GET /api/sightings/recent

Get 3 most recent sightings
